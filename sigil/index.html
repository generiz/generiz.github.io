La composición usa un teclado gráfico propio y evita la ruta IME normal, pero los bytes de entrada siguen siendo plaintext para el origen web. El core Rust/WASM genera secretos efímeros, sella un envelope con dos capas AEAD, lo fragmenta con Reed–Solomon y lo reconstruye en el mismo proceso. No hay AKE ni dos endpoints.

REAL: bytes → SymbolId → doble AEAD → shards → reconstrucción/autenticación.   NO EXPORTADO: plaintext reconstruido.   SIMULADO: topología de nodos.   FUERA DEL DEMO: distribución de secretos, firma de identidad, ratchet y red live.
